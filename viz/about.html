About the data

The Centralised Web Accessibility Checker (CWAC) automatically checks New Zealand government websites for accessibility problems and repeats the scan over time. The dashboard tracks whether things are getting better. This page explains, in plain language, where the data comes from and how to read each measure.

Source
CWAC Monitoring Programme data — data.govt.nz

The dashboard is built from cleaned versions of this open dataset. Nothing here is manually edited — the numbers come straight from the automated scans.

The measures

Each scan runs a set of automated checks. These are the measures you can pick on the dashboard.

MeasureWhat it meansBetter when
Pages scannedHow many pages the checker looked at in that scan. It shows how broad the scan was, not a problem count.higher
Serious + critical issuesAccessibility failures found by the axe-core checker, counting only the two most serious levels. These are the ones most likely to block someone.fewer
Serious / CriticalThe same issues split by how severe they are. Critical issues are the most blocking; serious ones are still important.fewer
Focus-indicator issuesWhether you can see which thing is selected as you move through a page with the keyboard (the visible outline). Missing outlines make keyboard use hard.fewer
Reflow at 320 pxPages that break — forcing you to scroll sideways — when the screen is very narrow or the text is zoomed in. Counts the pages that fail.fewer
Broken / blocked linksLinks that returned an error or an unexpected response when followed.fewer
Reading levelRoughly the school year of education needed to read the text comfortably (Flesch–Kincaid grade). Plainer writing reaches more people.lower

Reading the numbers

  • Compare per page, not totals. Scans covered very different numbers of pages over time (about 23,000 pages early on, about 55,000 by June 2026). To judge real progress, use the per-page view so bigger scans don’t look like more problems.
  • Blank points mean “not measured”, never zero. Not every check ran in every scan. A gap in a line just means that audit didn’t run then (the focus-indicator check ran in three of six scans; broken links in one).
  • Agencies and mergers. Government agencies merge and rename over time. Every website is credited to the agency that owns it today (as at 30 June 2026), so a merged agency keeps one continuous trend line back through its predecessors. 45 agencies are tracked.

The datasets

The dashboard reads a set of cleaned tables derived from the source data above. Each one answers a different question:

  • Government totals — one row per scan: the country-wide headline numbers.
  • By agency — each agency’s numbers over time (the main trend lines).
  • By website — the same, drilled down to individual sites an agency owns.
  • By sector — groups of agencies (e.g. public service departments, crown entities) over time.
  • Impact split — for each agency, how issues break down into critical / serious / moderate.
  • Top failing rules — for each agency, which specific WCAG checks fail most often.
  • All issues — the full detail: one row for every individual issue found.
  • Agency ↔ website map — which agency owns each website, plus its historical names.
